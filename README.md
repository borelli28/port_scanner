# Port Scanner App

A simple desktop port scanner app built with Dioxus 0.6.0. Scans IP addresses for open, closed, and filtered ports.

## How to Run

1. Ensure you have the Dioxus CLI (`dx`) installed.
    ```bash
    https://dioxuslabs.com/learn/0.6/getting_started/#install-the-dioxus-cli
    ```
2. Clone this repository.
    ```bash
    git clone https://github.com/borelli28/port_scanner.git
    ```
3. Navigate to the project directory.
    ```bash
    cd port_scanner/port_scanner
    ```
4. Run the following command:
    
    This will launch the app on your desktop.
    ```bash
    dx serve --platform desktop
    ```

    To run in a web browser on http://localhost:8080
    ```bash
    dx serve --platform web
    ```
